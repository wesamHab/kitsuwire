# KitsuWire

Modern editorial platform for clear intelligence across AI, technology, software and markets.

## Stack
- Next.js 15
- React 19
- TypeScript
- Responsive custom CSS
- Docker / standalone Next.js runtime

## Local development
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Docker
```bash
docker compose up --build
```

The production image listens on port `3000` and is suitable for container platforms such as Google Cloud Run.

## Product direction
KitsuWire is designed as a modern intelligence/media brand rather than a generic blog. Planned next steps include article routes, category pages, CMS/content pipeline, search, newsletter integration, sitemap/structured data, analytics and automated publishing workflows.
